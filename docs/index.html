SCENE 04 // ARCHITECTURE

          

            Decoupled by design. Zero lock-in.
          

        


        
        


          
          

            

              01 / PROVIDERS
              httpx + rapidfuzz
            

            
Multi-Source Async Aggregation

            

              Queries all active providers concurrently via asyncio.gather with fault isolation. Results are deduplicated and ranked by fuzzy similarity plus source fidelity (PDF > HTML > Transcript).
            

            

              

                IMSDbHTML
              

              

                Script SlugPDF
              

              

                TV WritingPDF
              

              

                SubsLikeScriptFallback
              

            

          


          
          

            

              02 / PARSERS
              PyMuPDF · XML
            

            
Coordinate & Bidirectional FDX

            

              Plain text dumps destroy screenplay structure. rtfs clusters PDF x0 bounding boxes dynamically, strips headers/revision stamps, parses IMSDb <b>/whitespace layouts, and reads/writes native Final Draft .fdx.
            

            

              
RawScript(pdf | html | fdx | text)

              
|--> ScriptDocument (Pydantic v2 AST)

              
`--> JSON · Fountain · FDX · Stats

            

          


          
          

            

              03 / CACHE LAYER
              Protocol + URI
            

            
Pluggable Async CacheBackend

            

              Zero-config SQLite-backed DiskCache out of the box, or switch backends via a single RTFS_CACHE_URL URI—no pickle serialization, strict bytes contract, and clean custom backend injection.
            

            

              

                disk://~/.cache/rtfs
                DEFAULT
              

              

                redis://localhost:6379/0
                rtfs[redis]
              

              

                memory://  |  none://
                CI / NO-OP
              

            

          


          
          

            

              04 / FASTMCP SERVER
              rtfs[mcp]
            

            
Progressive Disclosure for AI Agents

            

              Full screenplays run 30,000+ tokens. Instead of flooding context windows, rtfs mcp exposes 5 surgical tools so Claude Desktop, Cursor, and Claude Code navigate scripts scene-by-scene.
